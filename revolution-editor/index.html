The Wii modding editor, native on your Mac.

Revolution Editor brings everything you need to mod Wii and GameCube games into one app: a project navigator and purpose-built editors for tracks, levels, models, textures, music and menus, plus the disc tools it grew out of. Edit, preview in 3D, and test in Dolphin without leaving the window.

Important: Revolution Editor is for editing and testing homebrew mods of games you legally own. It contains no Nintendo code, keys or game data, and we do not condone piracy in any form.

Mod it all in one place.

From a raw disc image to a track running in Dolphin.

Mario Kart Wii track tools

Edit course data on a top-down canvas, retag collision, build the minimap and sky, design the intro camera, then check laps and preview the whole course in 3D.

Models & textures

Import OBJ and COLLADA, edit BRRES files, bake normal maps and compare against retail track budgets.

Hot Swap testing

Mark loose files and launch Dolphin with them swapped onto your base disc. No ISO rebuild, original disc untouched.

Double Dash ports

Bring Double Dash courses to Mario Kart Wii, or send your Wii tracks back the other way.

Music, text & menus

Loop-aware BRSTM editing from any audio file, BMG message tables, and UI layout previews.

Disc tools

Browse, extract and replace files, scrub and unscrub ISOs, trim, and manage partitions.

Wii homebrew

Build Wii apps in C, C++ or Swift with your own devkitPro and run them in Dolphin. Design the screen visually, wire logic with nodes, or let Claude Code, Codex or Antigravity help.

NSMBW level editor

Edit sprites, entrances, zones and paths in New Super Mario Bros. Wii levels.

Built-in Git

Stage, commit, pull and push from the toolbar, plus per-editor undo history you can jump around in.

From disc to Dolphin.

  1. 01

    Open a project

    Drop in a disc image or an extracted game folder. Archives expand like folders, and the sidebar stays in sync with Finder.

  2. 02

    Edit with real tools

    Every format opens in its own editor, with 3D previews, validators and a full undo history. Imports from Blender and other tools just work.

  3. 03

    Test and ship

    Verify your archive, hot swap it into Dolphin, and build for real hardware when you're ready.
