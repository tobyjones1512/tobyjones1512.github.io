New Super Mario Bros. Wii

Edit levels in a visual editor.

Open a level

A level archive opens straight into the level editor. If it opens as a plain archive, right-click and choose Edit Level.

Edit

  • Toggle Objects, Sprites, Entrances and Locations to focus.
  • Click anything to edit it in the inspector: entrances, zones, sprites, tiles and path nodes.
  • Run Verify Archive before testing.
