Guide

Disc tools

Browse, extract, replace, scrub, unscrub, trim and rearrange Wii disc images. This is the original Revolution Disk Scrubber, built into the editor.

Open the Disc Scrubber

Click Disc Scrubber in the toolbar, or choose File > Open > Wii/GCN Disc Image…. Add your key first if you haven't (see Getting started).

The disc appears as a tree: partitions, then the files inside each one.

Extract and replace files

  1. Select a file or folder in the disc tree.
  2. Save / Extract… writes it to your Mac.
  3. Replace… swaps in a file of your own. Use this for custom textures, models or fan translations.

To work on a whole disc as a project, use Open Wii/GCN Disc Image as Project… in the Workbench. Edited files are written back to the image when you save.

Scrub (shrink) an ISO

Wii discs are mostly padding. Scrubbing blanks the unused space so the image compresses to a fraction of its size.

  1. Choose Clean and Save….
  2. Pick a Scrub type: 0xFF is safe and needs no signing; TRUCHA zero-fills and fake-signs the ticket and TMD.
  3. Pick the Output: ISO only, DIFF only, or Both. Keep the DIFF if you ever want the original back.
  4. Optionally keep the cluster hash headers: a bigger file, but less to lose if something's wrong.

Unscrub

Unscrub… rebuilds the original image from a scrubbed ISO plus the DIFF this app produced for it.

DIFF files are specific to Revolution Editor. They are not compatible with the Windows Wii Scrubber's .dif format.

Trim

Trim ISO writes a copy cut off right after the last byte the disc actually uses, rounded up to a whole cluster. It is the size USB loaders expect, and it keeps everything a game can read.

Partitions

Right-click a partition in the tree for:

  • Delete Partition
  • Resize Partition (data size)…
  • Shrink Partition: defragments it, using Trucha
  • Shuffle Partitions: closes the gaps between them
  • Import / Export Crypted Partition…
  • Toggle Boot Mode: switch between the system menu and auto-boot

A Wii partition table holds at most three partitions in table 0. That's a console limit, not an app one.

GameCube discs

GameCube images have no encryption, so they open without a key. You can browse and extract them, and in a disc project, Save writes edited files back in place.
