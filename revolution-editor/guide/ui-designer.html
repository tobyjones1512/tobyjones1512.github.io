UI designer

Lay out a screen visually: drag, resize and style widgets.

Open it

A UI app or game project includes ui/main.wiiui. Double-click it. You can also add one with File > New > Wii Homebrew > UI Design.

Widgets

  • Rectangle, Label (text), Button (clickable with the Wii Remote) and Image.
  • Drag to move, drag the corner handle to resize, arrow keys to nudge, Delete to remove.
  • The Layers list is the draw order: the top is drawn last, on top.
  • Set the name, position, size, text, colours and whether it shows at the start on the right.
  • Hold Shift while dragging the corner handle to keep the widget's proportions.
  • In the inspector, Y counts up from the bottom of the screen, matching the node editor.
  • Right-click a widget (on the screen or in Layers) to Duplicate it, show or hide it at the start, change its layer (front, forward, backward, back), choose an image, or delete it.

Using it

A widget named go is UI.go in Swift and UI_GO in C. Handle button clicks with the On Button Pressed node or appOnButton. On the Wii, point and press A to click; HOME quits.

Widescreen

Tick 16:9 in the top bar to design for an 854 × 480 screen instead of 640 × 480. The app fills a widescreen TV and is letterboxed on a 4:3 one; a 4:3 design is still pillarboxed on a widescreen TV. Code that draws to the screen sees the wider width.

Images

Image widgets scale a picture to the widget's size. Pictures from elsewhere are copied into assets/.
