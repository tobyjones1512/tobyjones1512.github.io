Double Dash: a battle stage

Build a Mario Kart: Double Dash!! battle stage step by step.

Before you start

A Double Dash battle stage is built like a course (do the Double Dash course tutorial first), with different course data. Every retail stage has:

  • 8 start points, one per player, in a ring facing the middle.
  • No enemy route and no checkpoints.
  • Item boxes (Block City's move about).
  • Usually no respawn points.

1. Build it

  1. Make the arena model, with materials named as in the course tutorial: walls round the edge, a fall where you can drop off.
  2. Choose File > New > Mario Kart: Double Dash!! > Course from Model... and pick a battle slot (marked (battle), for example Block City).
  3. Press Create. For a battle slot you get the 8 starts in a ring, centred on your arena and placed on its floor.

2. Course data

Open *_course.bol. The editor shows a Battle Stage badge and checks it with battle rules.

  1. Drag the 8 start points where you want them, spread round the arena and facing in. Keep each one's player number.
  2. Add item boxes: right-click empty canvas, Add Object Here, type GeoItemBox, then ⌘D for more.
  3. Select everything and Snap to Ground.
  4. Press Make Testable to fill in anything missing.

Need course data from scratch? File > New > Mario Kart: Double Dash!! > Battle Stage Course Data (BOL)... makes one with the 8 starts.

3. Play it

  1. Right-click the .arc and choose Mark for Hot Swap > Mario Kart: Double Dash!! > Battle Maps, then the stage to replace.
  2. Press Run, fix anything the checks find (Auto Correct where offered), and start a battle on the stage you replaced.

More in Testing your mod.

If it freezes

  • A battle stage needs exactly 8 start points: the editor only shows the Battle Stage badge when it has them.
  • Leave out checkpoints and the enemy route: they're for races.
  • If an object's models are missing, accept the banner that imports them.
