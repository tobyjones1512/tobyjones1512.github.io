The guide.

Step-by-step tutorials and reference for every part of Revolution Editor. New here? Start with Getting started.

Getting started

Install Revolution Editor, point it at your own keys and discs, and learn your way around the workbench.

Disc tools

Browse, extract, replace, scrub, unscrub, trim and rearrange Wii disc images. This is the original Revolution Disk Scrubber, built into the editor.

Archives (SZS / ARC)

Browse and edit the compressed archives almost every Wii and GameCube game is built from.

Mario Kart Wii tracks

The full track-making toolkit: course data, collision, minimap, sky, cameras, 3D preview and render.

Models & textures

Edit BRRES files, import OBJ and COLLADA models, and work with textures, normal maps and images.

Audio, text & menus

Make custom music, edit in-game text, and preview menu layouts.

Mario Kart: Double Dash!!

Port courses between Double Dash and Mario Kart Wii, in both directions.

New Super Mario Bros. Wii

Open and edit level archives in a visual level editor.

Wii homebrew

Write, build and run your own Wii apps in C or C++, powered by your own devkitPro install.

Swift

Write Wii app logic in Swift. It's translated to C and built with devkitPro.

UI designer

Lay out a Wii app's screen visually: drag, resize and style widgets, then build it into C.

Node editor

Build app logic by wiring blocks together instead of writing code. It's turned into C when you build.

Coding agents

Have Claude Code, Codex or Antigravity help build your homebrew apps, using your own accounts.

Testing & shipping

Run your mod in Dolphin, check it, and keep a history of your work.

FAQ & troubleshooting

Quick answers to the questions that come up most.
