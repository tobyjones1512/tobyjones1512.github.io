Audio, text & menus

Make custom music, edit in-game text and preview menu screens.

Music (BRSTM)

  1. Right-click an audio file (WAV, MP3, M4A, FLAC…) and choose Make .brstm, or open a .brstm.
  2. Drag the Loop and End markers on the waveform.
  3. Use Play Loop Seam to hear the jump back to the start, then save.

Text (BMG)

Edit messages by ID and add new ones. A lock marks a message with a special control code, which is read-only so it can't be broken.

Menus

Open a .brlyt layout to move its panes, or use Preview UI on a UI .szs to see every screen as the game draws it. .brsar sound archives open in a read-only browser.
