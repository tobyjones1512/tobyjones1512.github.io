Coding agents

Have Claude Code, Codex or Antigravity help build your homebrew apps, using your own accounts.

What this is

Revolution Editor doesn't include an AI model and never talks to one. Instead it links to the agent tools you already have installed, runs them in your project folder, and gives them what they need to be useful: a description of the project and a way to build and check it. You sign in to those tools yourself, and any usage is billed by them.

  • Claude Code and Codex run headlessly from the Agent button, and their output streams into the window.
  • Antigravity is an app, so Revolution Editor opens the project in it, and you work there.

Set up

  1. Install the agents you want from their own sites and sign in to them.
  2. Open Settings > Agents. Each one shows whether it was found; use Choose… if it wasn't.
  3. Open a homebrew project (any template).

Ask for something

  1. Click Agent in the toolbar (the sparkles button).
  2. Pick an agent, describe what you want (“add a score counter that goes up when I press A”) and press Run.
  3. Watch the output. Files the agent changes appear in the Project Navigator as it works, and open tabs refresh.
  4. Stop ends the run.
Use Source Control (Git) so you can see what an agent changed and undo it. Initialise a repository before a big request.

What the agent is given

When you create a project, or press Refresh Agent Files, these are written to the project folder:

  • AGENTS.md: the project layout, the UI and node file formats, the Swift subset and its built-in functions, the C API, and how to build. Codex and Antigravity read this file automatically.
  • CLAUDE.md: points Claude Code at AGENTS.md.
  • build.sh: ./build.sh --check translates Swift, UI and nodes to C and reports errors in a second; ./build.sh builds the .dol; ./build.sh --clean cleans.

Files you wrote yourself are never overwritten. Only ones Revolution Editor generated are kept up to date.

Permissions and commands

By default Claude Code runs with --permission-mode acceptEdits and may run only ./build.sh. Codex runs with --full-auto, which keeps it inside the project folder. Your request is passed as a single argument, never through a shell.

The command for each agent is editable in Settings > Agents: {prompt} stands for your request, and Reset restores the default. That's also how to adapt to a new version of an agent's command-line options.

Any other agent

Anything that can run a shell command can use ./build.sh --check and ./build.sh. Point it at AGENTS.md and ask it to check its work with the build script.

Privacy

Your request and the project files the agent reads go to whichever service that agent uses, under its own terms. Revolution Editor itself sends nothing anywhere.
