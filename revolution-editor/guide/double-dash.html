Mario Kart: Double Dash!!

Make Double Dash tracks and battle arenas with the same tools as Mario Kart Wii tracks, or move tracks between the two games. New to it? Follow the track tutorial or the battle arena tutorial.

Set up

In Settings > Games, link your Double Dash disc and turn on its tools. The disc is where each slot's minimap area, retail skies and object models come from.

A new track

File > New > Mario Kart: Double Dash!! > Track from Model... builds a slot's archives from your .obj or .dae: the model, collision (surfaces guessed from material names), a minimap, an optional sky, a start point and an intro camera. Then open the archive to draw the enemy route and checkpoints. The same menu makes course data (BOL), battle arena course data (8 starts), collision (BCO) from a model, and a sky (your own, or any retail track's).

Course data (BOL)

A .bol opens in the same editor as a Mario Kart Wii .kmp: the pen tool, Snap to Ground, the right-click menu (add points before or after, duplicate, delete) and ⌘D all work.

  • Check Laps checks it the way Double Dash needs: one start, a looping enemy route, convex checkpoint quads (a bent one freezes the game while loading), respawns that rejoin the route, and intro cameras that don't loop.
  • Make Testable fixes most of what Check Laps finds. It follows retail, so it doesn't add respawn points (battle arenas and Luigi Circuit have none).
  • A battle arena shows a Battle Arena badge and is checked with battle rules.
  • If an object needs models the track doesn't have, a banner imports them into its objects folder from your disc.

Track tools

Right-click a track .arc and open Mario Kart: Double Dash!!:

  • Edit Track in 3D...: the 3D track editor, as for Wii tracks.
  • Scale Track...: scales the track and sky models, collision and every course-data point together. Double Dash fixes each slot's minimap area, so redraw the minimap afterwards.
  • Minimap Editor...: redraws the minimap from the collision. Tick the surfaces that belong on it and set the outline, with a live preview.
  • Create Shadow Map...: the same sun controls and live 3D preview as the Wii version. Double Dash shades tracks through vertex colours, so the shadows are baked into them. Also on a loose _course.bmd.

Opening a .bmd shows Track Budget: its triangles, vertices, draw calls and texture memory next to every retail Double Dash track.

Double Dash to Mario Kart Wii

Right-click a track archive and choose Port > To Mario Kart Wii. Pick a scale (around 1.18 matches Nintendo's own remake of Mario Circuit). You get a .szs with the model, sky, collision, minimap and course data. Mark it for Hot Swap onto the slot you want to replace.

Mario Kart Wii to Double Dash

Right-click a track .szs and choose To Double Dash…. Pick the slot to replace. The app writes both the single-player and multiplayer archives and repairs checkpoints Double Dash can't handle.

Testing

Mark the track for Hot Swap onto a Double Dash slot and press Run. The same checks as for Wii tracks run first: errors stop it (with Auto Correct where the fix is mechanical, such as running Make Testable), and suggestions point out missing item boxes or cameras. See Testing your mod.
