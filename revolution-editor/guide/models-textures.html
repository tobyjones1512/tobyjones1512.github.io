Models & textures

Edit BRRES files, import OBJ and COLLADA models, and work with textures.

BRRES editor

A BRRES holds a model, its textures and animations. Select a resource to see it (drag to orbit a model). You can add a texture from an image or a model from an .obj, replace or export a texture as PNG, rename and delete.

Importing models

Everywhere you can import an .obj you can import a COLLADA .dae too. In Settings > Games, Build for picks Dolphin-compatible (small, quick) or Hardware-compatible (what a real Wii needs).

Normal maps

Right-click a texture and choose Normal Map… to create one from its brightness, or to bake relief into the texture. Mario Kart Wii has no per-pixel lighting, so the effect is baked in.

Viewers

TPL texture banks, OBJ models and images open as read-only previews. Text and source files open in a code editor with detailed colour coding (keywords, types, functions, macros, strings and escapes, numbers, attributes), line numbers, Find, and automatic code completion: suggestions appear as you type and Return or Tab accepts one (for C and C++ that includes the Wii runtime and libogc; for Swift the homebrew API). The toolbar's View options turn on a minimap, code folding (with Fold All and Unfold All), a status bar and word wrap, and Go to Line… is ⌘L. Markdown files open as a formatted preview; switch to Edit to change them. Settings > Code Editor sets the font, tab width, auto-indent, auto-closing brackets, completion and colour theme (System, Midnight, Daylight, Solarized Dark, Monokai, or your own colours). If you set a code editor such as VS Code in Settings > External Editors, an Open in button sends the file there, and edits show up here when you switch back.
