Getting started

Install Revolution Editor and open your first project.

What you need

  • A Mac running macOS 27 or later.
  • Your own game files: a disc image, or an extracted game folder.
  • For Wii discs, your own key.bin. The app never includes or downloads one.
  • Optional: Dolphin, a free emulator, to test your work.
Your own games only. Revolution Editor contains no Nintendo code, keys or game data.

Install

  1. Download it from Gumroad.
  2. Drag Revolution Editor into your Applications folder and open it.

Add your key

Wii discs are encrypted. Open Settings > Keys, choose your key.bin, and the app remembers it. Extracted folders and GameCube images don't need one.

Open something

  • File > Open > File… ⌘O for a single file.
  • Folder… ⇧⌘O for a project folder.
  • Wii/GCN Disc Image… to browse a disc.

The window has your files on the left, an editor for each file type in the middle, and a console at the bottom. The sidebar updates by itself when files change in Finder.

Good to know

  • Every editor has Undo and a History list you can jump around in.
  • Right-click a file or folder for New, Rename, Duplicate, Extract and more.
  • Settings is where you link your own game discs, set the Dolphin location and choose how models are built.
