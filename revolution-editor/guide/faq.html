FAQ

Quick answers to common questions.

General

Does it include games, keys or an emulator?

No. You bring your own discs, key and (optionally) Dolphin.

Can I download games with it?

No, and it never will.

Is this Wii Scrubber?

It started as a Mac take on Wii Scrubber and still has all of its disc tools. It's an independent app; no Nintendo or Dolphin code is inside.

Modding

My Wii disc won't open.

Check Settings > Keys. A 16-byte key.bin is needed.

My track crashes on a real Wii but not in Dolphin.

Set Build for to Hardware-compatible, rebuild, and check the Track Budget.

My imported model is on its side.

Most 3D tools use Z-up. Tick Convert Z-up to Y-up when importing.

An object is missing in my track.

Link your Mario Kart Wii disc in Settings > Games; a banner will offer to copy the files.

Homebrew

Does SwiftUI work?

A practical part of it: stacks, text, buttons, toggles, sliders, shapes and the usual modifiers. See SwiftUI.

Can I really write Wii apps in Swift?

A subset of it, translated to C. See Swift.

Can I make a game?

Yes. See Make a game.

Does it use AI?

No. It can run Claude Code or Codex you've installed, or open Antigravity. See Coding agents.

The build says devkitPro wasn't found.

Install devkitPro with the wii-dev group, or choose its folder in Settings > Homebrew.

Still stuck?

Email hello@thecaffeinemediacompany.com with what happened, your macOS version and a screenshot if you can.
