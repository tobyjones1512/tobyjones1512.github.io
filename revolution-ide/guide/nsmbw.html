New Super Mario Bros. Wii

Open and edit level archives in a visual level editor.

Opening a level

A level is a U8 archive with a course folder holding up to four areas. Revolution IDE recognises one by its contents, not its extension, so an .arc or .szs level opens straight into the level editor. Right-click and choose Edit Level if you opened it as a plain archive, or Open in New Window for a dedicated window.

The editor

  • Canvas with a zoom control. Toggle Objects, Sprites, Entrances and Locations on and off to see only what you're working on.
  • Inspector: click anything on the canvas to edit it. Entrances, locations, zones, sprite types and settings, tile objects (with tileset and layer), and path nodes.
  • Add entrances, locations, objects and sprites, and add or remove path nodes.
  • Area summary for a quick overview of each area.

Before you ship

Run Verify Archive on the level to confirm it parses and has everything NSMBW expects. Test it with Hot Swap or Run in Emulator.
