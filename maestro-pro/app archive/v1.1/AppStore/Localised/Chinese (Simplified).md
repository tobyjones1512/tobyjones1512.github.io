## Description (4000)

Maestro Pro 是会跟着你一起演奏的乐谱。

打开乐谱，点击播放。每个音符随声音亮起，柔和的光带标出当前小节，页面会在你需要的时刻恰好滚动或翻页。把难的乐段放慢而不改变音高，循环几个小节，先数拍再开始，打开节拍器，或把整首曲子移调给单簧管、小号或萨克斯。乐谱会按新调重新排版，而不只是改个标签。

导入你自己的音乐
导入 PDF、MusicXML（.musicxml、.xml、.mxl）、MIDI 和卡拉 OK（.mid、.kar）文件、歌词（.lrc、.txt）以及 CD+Graphics 卡拉 OK（.cdg）。可一次导入整个文件夹。把乐谱库保存在设备上，或存入你自己的 iCloud 云盘，所有设备都能使用。

搜索乐谱
“搜索乐谱”可从内置的古典与爵士曲库以及更广泛的网络中找到免费乐谱，让你一分钟内开始演奏。

伴奏与歌词
添加伴奏音轨，或跟着 Apple Music 订阅中的歌曲演奏。匹配调性与速度，叠加多条音轨，并看着歌词随节拍滚动。二重唱和合唱歌曲会为每位歌手分配一种颜色，长时间间奏时歌词会显示停顿。

认真练习
- 等我：乐谱会等你弹对音符再继续。
- 调音器和长音练习器。
- 对着乐谱录音，查看每个错音、迟到的进入和需要加强的小节。
- 随时生成任意调的音阶和琶音。
- 用 Apple Pencil 在页面上做标记，导出 PDF 时笔迹也会包含在内。

写谱与编辑
改正错音、添加和声或写下新作品。触摸音符上下滑动，在上面涂抹即可擦除，轻点时值即可更改。编辑器会替你保持符杆、连音线和小节长度整齐。每次存储都是一个可以返回的版本：在分支上尝试想法，逐小节合并回来，并把完整历史推送到你自己的 GitHub 仓库。

一起演奏
最多连接八台设备，让每个人都严丝合缝地同步演奏，各自使用自己的声部、调性和乐器。

分享与打印
导出 MusicXML 或 PDF、打印、制作音乐跟随播放的视频，或把 Maestro Pro 文件发给其他演奏者。

为教学而生
学生有耐心的练习伙伴，教师也能更快准备分谱、带领合奏。

在 iPhone 上
在 iPhone 上，Maestro Pro 是查看你在 iPad 或 Mac 上添加的乐谱的阅读器，带调音器和免手动自动滚动。完整应用可在 iPad、Mac 和展开的 iPhone Duo 上使用。免费版可查看最多 3 份乐谱。

隐私
无需账户，没有广告。你的乐谱和录音只保存在你的设备和你自己的 iCloud 中。匿名、保护隐私的使用统计帮助我们改进应用，除此之外，应用只会在你要求时联网。

Maestro Pro 由英格兰的 Toby Jones 制作。
