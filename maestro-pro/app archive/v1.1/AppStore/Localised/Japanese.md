## Description (4000)

Maestro Pro は、あなたと一緒に演奏してくれる楽譜です。

楽譜を開いて再生を押すだけ。音が鳴るたびに音符が光り、やわらかな光が小節を示し、ページは必要なタイミングでスクロールまたはめくれます。難しい箇所は音程を変えずにゆっくりに、数小節をループ、カウントイン、メトロノーム、クラリネットやトランペット、サックス向けに曲全体を移調。楽譜は新しいキーで組み直されます。

自分の音楽を持ち込む
PDF、MusicXML（.musicxml、.xml、.mxl）、MIDI・カラオケ（.mid、.kar）ファイル、歌詞（.lrc、.txt）、CD+G カラオケ（.cdg）を読み込めます。フォルダごとまとめて読み込みも可能。ライブラリはデバイス内、またはご自身の iCloud Drive に保存して、すべてのデバイスで使えます。

楽譜を探す
「楽譜を検索」では、内蔵のクラシックとジャズのカタログやウェブ全体から無料の楽譜を探せるので、すぐに演奏を始められます。

伴奏と歌詞
伴奏トラックを追加したり、Apple Music の曲に合わせて演奏したり。キーとテンポを合わせ、複数のトラックを重ね、歌詞が拍に合わせて流れるのを見られます。デュエットやグループの曲では歌い手ごとに色分けされ、長い間奏では歌詞が一時停止を示します。

しっかり練習
- 待っていてね：正しい音を弾くまで楽譜が待ちます。
- チューナーと音の安定トレーナー。
- 楽譜に合わせて録音し、間違った音、遅れた入り、練習すべき小節を確認。
- どのキーでも、スケールとアルペジオをその場で作成。
- Apple Pencil でページに書き込み。PDF の書き出し時にも反映されます。

書いて、編集する
間違った音を直し、ハーモニーを足し、新しい曲を書けます。音符に触れて上下にスライド、なぞって消去、音価をタップして変更。連桁、タイ、小節の長さはエディタが整えます。保存のたびに戻れるバージョンが残り、ブランチでアイデアを試し、小節ごとに統合し、履歴全体をご自身の GitHub リポジトリへプッシュできます。

一緒に演奏
最大 8 台のデバイスをつないで、全員がぴったり同じタイミングで演奏。それぞれのパート、キー、楽器で参加できます。

共有と印刷
MusicXML や PDF の書き出し、印刷、音楽に合わせて動く動画の作成、Maestro Pro ファイルを他の演奏者に送ることができます。

レッスンにも
生徒には辛抱強い練習パートナー、先生にはパート準備やアンサンブル運営の近道に。

iPhone では
iPhone の Maestro Pro は、iPad や Mac で追加した楽譜を表示するビューアで、チューナーとハンズフリーの自動スクロールが使えます。フル機能のアプリは iPad、Mac、開いた iPhone Duo で動作します。無料プランでは最大 3 曲の楽譜を表示できます。

プライバシー
アカウント不要、広告なし。楽譜と録音はデバイス内とご自身の iCloud にのみ保存されます。アプリ改善のため、匿名でプライバシーに配慮した利用回数を集計しますが、それ以外でインターネットを使うのはご自身が操作したときだけです。

Maestro Pro はイギリスの Toby Jones が作りました。
