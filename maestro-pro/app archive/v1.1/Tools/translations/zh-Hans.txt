1097|快速入门
1098|Maestro Pro 是为音乐人打造的工作工具:它读取你的乐谱并逐音跟随,免手翻页,可配合伴奏、Apple Music 歌曲、内置乐器或节拍器排练,还能让你亲自编写和修订音乐。
1099|最初的一分钟
1100|在主屏幕上点按“导入乐谱”(或点按 + 按钮,再选“导入乐谱”),选择 PDF、MusicXML 文件或其他受支持的文件。它会出现在左侧的资料库中,点按即可打开。
1101|按下底部的大“播放”按钮。音乐开始播放,乐谱随之跟随。点按乐谱上的任意位置可从那里开始,也可拖动进度条。
1102|还没有可演奏的内容?在主屏幕上选择“打开示例”,或选择“搜索乐谱”下载古典乐曲和爵士曲目,也可以搜索网络。
1103|简易模式与高级模式
1104|“设置”中有“模式”开关。简易模式让屏幕只保留大多数人需要的内容。高级模式增加资料库工具、一起演奏、逐谱表控制以及“自定每种颜色”页面。
1105|本指南描述的所有内容都可在高级模式中使用;每个主题会说明哪些控件只在高级模式中出现。
1106|工具栏
1107|在 iPad 上,工具栏保留最常用的少数控件(打开、缩放、伴奏与声音、标注、编辑),其余都放在末尾的“更多”菜单中:上面是工具,然后是页面、演奏时显示的内容、歌词,最后是伴奏。Mac 则把每个控件显示为单独的按钮。
1108|“设置”只在资料库中,所以不在乐谱的工具栏上。要回到资料库,请用左上角的按钮显示边栏。

1110|在 iPad 上,轻触并按住工具栏(或点按末尾的 ⋯ 并选择“自定工具栏”),即可把控件拖入或拖出工具栏;在 Mac 上,选择“显示”▸“自定工具栏”。“检查器”按钮始终保留。

1149|在检查器中,“调”提供你的乐器的调(实际音高、降B、降E 或降B次中音)。乐谱会相应地移调显示,因此小号手读到的就是小号演奏的音。
1150|“移调”以半音为单位整体上移或下移乐曲。“调”菜单列出每个调及其关系小调,例如 C / A 小调;选择一个,乐谱就会走最短的路径移到该调。
1151|有伴奏时,“移动伴奏”决定伴奏是否随乐谱一起移动。
1152|和弦视图(高级模式)
1153|工具栏中的“和弦视图”按钮(方格网格),或“更多”▸“和弦视图”,会把乐曲显示为和弦表,每小节一格,带反复记号、结尾和跳转。正在播放的小节会亮起,表会滚动跟随;点按某小节可从那里开始演奏。
1154|如果文件带有和弦记号,则按原样显示。否则 App 会根据音符推断和弦:4/4 每小节两个,3/4 和 6/8 每小节一个:大小三和弦、减三和弦、增三和弦和七和弦,低音不是根音时带斜线。这只是推测,有低音线或伴奏时最准确,单纯的旋律会得到一个合理的三和弦。
1155|和弦随你选择的调变化,并相应地用降号或升号拼写。用“缩放”可使和弦更大或更小。
1156|显示的记谱
1157|除了音符、休止符、变音记号、连音线、连音符、反复、结尾、Segno、Coda 等之外,乐谱还会显示圆滑线、装饰音(在主音之前一瞬间发声的带斜线小音符)、颤音、波音和回音、指法数字、琶音波浪线、换气记号和停顿、八度线(8va、8vb、15ma、15mb)以及踏板记号(Ped. 和松开星号)。

1159|一个谱表上同时打开多条圆滑线的乐谱会绘制最新的一条,八度线只显示而不改变声音。
1160|音符下方的歌词

1162|力度
1163|乐谱中的力度(ppp 到 fff)以及渐强和渐弱的括线决定内置乐器的音量:一个音符与上一个力度同样响,括线会稳步把它变向下一个力度。没有力度的乐谱以统一电平播放。
1164|你可以在乐谱编辑器的“力度”模式中添加它们,它们会随乐谱保存。
1165|速度
1166|速度以每分钟拍数计。可键入、逐步调整或拖动滑块。有伴奏时,“在此固定速度”会根据你在强拍上点按的位置设定速度。
1167|“拍号”告诉 App 一个小节有几拍。MusicXML 文件会自动识别;PDF 在无法判断时 App 会询问。
1168|如果乐谱有速度标记(♩ = 96),它们会从该小节起改变内置乐器的速度。伴奏保持自己的速度。
1169|调音器与等我
1170|Maestro Pro 可以通过麦克风聆听:为你的乐器调音、训练稳定的音,以及逐音等你演奏乐谱。声音在设备上分析,绝不会被录制或发送到任何地方。
1171|从主屏幕、+ 菜单、“设置”▸“聆听”,或乐谱工具栏中的音叉打开调音器。演奏一个音:显示屏会显示它的名称、偏高或偏低多少音分(一音分是半音的百分之一)和频率。音准时指针会落在绿区,下方的轨迹显示最近八秒。
1172|如果你的乐器在检查器中设为降B或降E,还会显示记谱音。“播放参考音”会发出你要对准的音。A = 440 Hz 可更改(415 到 466),用于巴洛克或管弦乐调音。
1173|调音器下方,当你把音保持在准确音高时圆环会填满。可选“任意音”,或选一个要保持的特定音;选择多接近算音准(严格 ±5¢,正常 ±10¢,宽松 ±20¢)以及目标(5 到 30 秒)。它会显示你的最佳时间和音高的稳定程度。
1174|晃动或换成别的音会让计时重新开始。目标会替你计数,所以你可以尝试打破它们。
1175|“等我”是音乐等你的练习模式。打开乐谱并选择“等我”(耳朵图标,或“更多”▸“等我”)。乐谱停在第一个音上。只有当你在正确的八度、音准无误地演奏该音,并按当前速度和练习速度保持足够时长,它才会继续。
1176|播放栏上方的面板显示要演奏的音、音高表(圆点应落在绿区)和你保持时逐渐填满的条。它会告诉你偏高、偏低还是弹了别的音。“听这个音”替你演奏;“返回”和“跳过”移动一个音;滑块按钮选择要跟随的声部(钢琴谱有两个)、严格程度、每个音必须保持多少,以及是否接受任意八度(适合人声)。
1177|重复的音需要重新开始,所以让第一个音先停下再弹下一个。结束时你会看到准确率以及平均偏离音符多远。你演奏和弦中任意一个音都算数;此模式一次只跟随一条线。
1178|“等我”开启时,伴奏保持静音(乐谱在等你,伴奏无法跟上)。按“播放”即可结束。
1179|麦克风提示
1180|“设置”▸“聆听”中有“麦克风灵敏度”:在安静的房间里或乐器声音轻柔时调高,拾取到噪声时调低。安静的房间效果最好,并且一次只弹一个音。“等我”和调音器需要麦克风权限;如果你拒绝了,请在设备“设置”▸“隐私”▸“麦克风”中开启。
1181|录音与回听
1182|录下你演奏乐谱的过程,然后在音符点亮的情况下回听:绿色表示你应该所在的位置,红色表示你实际所在的位置。它通过麦克风聆听,因此适用于任何乐器或你的声音。
1183|选择“录音”(工具栏中的圆形录音按钮,或“更多”▸“录下我的演奏”,或 Mac 上的 ⌘R)。预备拍之后乐谱开始播放,你跟着演奏。完成后按“停止”或暂停。
1184|录音时内置乐器和节拍器会静音,让麦克风只听到你。如果乐谱有伴奏,App 会先询问,因为麦克风会听到它:选择“静音并录音”(之后会恢复),或使用耳机时选择“仍然录音”。录音栏上也有“静音”按钮。第一次时,App 会请求使用麦克风。
1185|录音与乐谱一同保存,因此复制乐谱时会一并复制。每段都压缩到每分钟远小于一兆字节。
1186|回听
1187|停止后,回听会立即打开。之前的录音在“录音”菜单中,最新的在前。按“播放”可边听录音边看乐谱跟随,或拖动滑块到任意时刻。
1188|绿色音符是你在那一刻应该演奏的音。你实际演奏的音也会点亮:音对、时间对时为绿色,晚了、早了或与应演奏的音不同时为红色。如果你落后或抢拍,无论差多远,你应在的音是绿色,你仍在演奏的音是红色。
1189|如果你弹的音在那附近的乐谱中没有,则应演奏的音是绿色,条带显示你弹的音高。摘要会给出你弹对了多少个音。
1190|滑块按钮选择要评判的声部(钢琴谱有两个)、节奏的严格程度(严格、正常或宽松)、音高多接近算对,以及是否接受任意八度。更改它们会重新评判同一段录音。“删除此录音”会将其移除。
1191|回听中的闪光按钮会写一份简短的点评:弹对了多少音、你在哪里落后或抢拍、偏高还是偏低,以及哪些小节和音符有困难。内容简明扼要。
1192|点评中的位置(小节和音符,以音符或小节线显示)是链接。点按其中一个,录音会跳到那一刻,乐谱中的音符亮成蓝色,页面翻动或滚动到那里。编号方块的一行按表现为每个小节着色,每个也是链接。
1193|在支持 Apple Intelligence 的设备上,点评由设备上的模型组织成文字,任何内容都不会离开设备。事实始终来自 App 自己的分析,任何改变数字或位置的改写都会被丢弃。没有 Apple Intelligence 时由 App 自己撰写。“重新撰写”会请求新的措辞。
1194|需要了解的
1195|它一次只听一个音,所以你演奏和弦中任何一个音都算数。时间按乐谱的时钟判断,而不是按录音的声音,因此很慢或很快的录音会按你录音时的速度来评判。
1196|请把它当作参考。嘈杂的房间、微弱的信号,或八度难以听清的乐器,都可能让音符看起来不对;“设置”▸“聆听”中的“麦克风灵敏度”会有帮助。
1197|伴奏与声音
1198|伴奏是与乐谱一起播放的录音。内置乐器也可以演奏页面上的音符。
1199|多条音轨
1200|一份乐谱可以有多条伴奏,例如节奏组和单独的示范人声。用“添加伴奏”添加第一条,然后在检查器或声音菜单中使用“再添加一条伴奏”。它们会一起播放,与乐谱同步。
1201|在“伴奏与声音”下,每条音轨都有自己的开关,可在不移除的情况下关闭,还有自己从 -24 到 +12 分贝的电平。第一条音轨是乐谱据以计时的那条,“匹配调与速度”和音轨编辑器作用于它。其他音轨跟随它的速度和调,但不跟随它的编辑轨道,并且应是与它同时开始的录音。

1207|在检查器或工具栏中选择“添加伴奏”并选一个音频文件。App 会聆听它,并设置乐谱的速度和调以匹配,使其准时开始。
1208|如果乐谱没有对齐,请把音轨上的标记拖到第 1 小节开始的位置,或延迟音轨。“延迟开始”可以按秒或按小节。如果在乐曲后面漂移,请在更靠后的强拍上点按“固定速度”。

1210|编辑音轨

1212|每个点可以是直线或平滑的 S 形曲线。可用它来淡入淡出、缓和速度变化,或校正略微走音的音轨。
1213|内置乐器
1214|“演奏乐谱用”选择演奏页面音符的音色(或“关”):钢琴、管风琴、吉他、贝斯、长笛、单簧管、萨克斯或小号。在检查器中,“乐器增益”和“伴奏增益”各为该乐谱设定从 -24 到 +12 分贝的电平,用来平衡乐器与伴奏;箭头可重置为 0。“设置”中有乐器的起始音量。它可与任何伴奏一起演奏。

1217|编写与编辑音乐
1218|乐谱编辑器修改 MusicXML 乐谱的音符。PDF 先由 App 读取,编辑器处理的是它读取内容的副本。用“编辑乐谱”(音符列表按钮;在简易模式下,它会出现在你创建的乐谱上)打开。
1219|九种模式
1220|编辑器底部的条带为每类工作提供一种模式,使一项工作的控件集中在一起。滑动条带可看到其余部分。

1227|串烧:在小节上拖动以选择,然后“拷贝”“剪切”“粘贴”“复制”或“删除”,或“从乐谱插入”以从资料库中的另一份乐谱取小节。

1235|快捷菜单
1236|点按一个音符,上方会悬出一个小菜单,列出你最常用的操作:升号、降号、还原号、连音线、附点、力度,以及变为休止符。点按休止符可选缩短、加长和移除。点按小节的空白部分可选反复开始和结束、添加小节和删除小节。

1238|时值、附点、三连音和连音线
1239|音符按钮选择全音符、二分音符、四分音符、八分音符和十六分音符的时值。附点使时值延长一半。“3”产生三连音:三个音占两个音的时间,以括号和 3 显示。

1242|编辑器为你做的事
1243|默认情况下,编辑器会照看小节。音符绝不会超出小节线。较长的音符会占据小节中它后面的位置;较短的音符会留下休止符,按抄谱员的写法书写(落在拍点上,而不是跨过拍点)。符杠会自动添加,保存时短小节会用休止符补满。

1245|“自由编辑”(选项,右上角)会关闭以上所有。音符恰好是你选择的长度,从不被小节截断,从不覆盖相邻音符,也不留下休止符。小节可以有过多或过少的拍。触摸小节中的空白处可在最后一个音符后添加音符。保存时不会整理任何内容。
1246|小节、反复与速度
1247|在“小节”模式中选择一个小节。“开始”和“结束”在其上放置反复记号(“结束”可循环两次、三次和四次)。“第一次结尾”和“第二次结尾”在其上放一个括号;“延长括号”和“缩短”把它延伸到相邻小节;“无结尾括号”将其移除。
1248|“跳转”可添加 Segno、Coda、To Coda、Fine,以及 D.C. 或 D.S.(普通、al Coda 或 al Fine)。把 Segno 放在 D.S. 返回的地方,把 To Coda 放在音乐跳出的小节,把 Coda 放在它跳到的小节。播放会遵循它们:D.C. 或 D.S. 之后不再重复段落,演奏最后的结尾,然后从 To Coda 跳到 Coda(或在 Fine 停止)。
1249|“展开反复”把乐曲按实际演奏的样子写出来,每个反复、结尾和跳转各自成为独立的小节。
1250|“速度”在小节上设置印刷的 ♩ = 标记;播放从那里起遵循它。
1251|“在后面添加小节”和“删除小节”会改变乐曲的长度。
1252|撤销、保存与分享
1253|“撤销”和“重做”在面板中,Command-Z / Shift-Command-Z、三指轻扫或摇晃 iPad 也可使用。在“绘制”模式中,那里的“撤销”和“重做”撤销的是绘制。
1254|“存储”保留你的更改;“取消”会在丢弃前询问。选项中的“恢复原始乐谱”会找回你导入的内容。
1255|“仅用 Apple Pencil 编辑”(选项)阻止手指更改音符,所以手搁在页面上也不会有影响。
1256|歌词与卡拉OK
1257|歌词像 Apple Music 一样随音乐滚动,CD+Graphics 卡拉OK文件显示它们的内置画面。
1258|歌词文件
1259|从“歌词”菜单给乐谱添加 .lrc 文件(带时间的行)或 .txt 文件。卡拉OK MIDI(.kar)文件包含自己的歌词。
1260|“显示歌词而非乐谱”把页面换成歌词。“音节动画”让每个音节在演唱时膨胀,“显示音节进度”将其填满。字体、大小、对齐方式以及未演唱行的模糊程度在“设置”中。
1261|仅歌词项目(无记谱)有自己的屏幕,带播放栏和可选伴奏。文件没有时间信息时,可选择按秒或按小节显示歌词。
1262|演唱者与间奏
1263|对于二重唱,“分配演唱者”把每一行分给一位演唱者;“匹配演唱者”从歌曲在 Genius 上的页面查找。一位演唱者,或一位加所有人,留在左侧;两位或更多则分在左右,各有自己的颜色。
1264|用“演唱者”筛选器显示某位演唱者的行。另一位演唱时,空档会显示省略号。“设置”中“间奏”里的“进度条”把圆点换成一条在空档中填满的条。
1265|CD+Graphics(.cdg)
1266|.cdg 文件是卡拉OK光盘的画面轨道:它在小屏幕上绘制彩色歌词和背景。App 按文件自身的时间播放它。如果有歌曲的音频,请将其作为伴奏添加。
1267|分享、导出与打印
1268|把乐谱或其视频带出 App。
1269|分享菜单
1270|在资料库中按住乐谱并选择“分享”。它有“导出为 MusicXML”“导出为 PDF”和“打印”。
1271|MusicXML 可在 MuseScore、Finale、Sibelius、Dorico、Notion 和大多数其他记谱 App 中打开。对于 PDF 乐谱,它是 App 从页面读取的音乐。
1272|PDF 是印刷页面。PDF 乐谱按原样传递;其他任何乐谱按当前显示的调排版。“打印”打开系统打印对话框。
1273|在分享面板中,你还可以“存储到文件”、通过 AirDrop、邮件或信息发送文件。
1274|其他输出方式
1275|“与其他演奏者分享”(高级模式,同一菜单)会生成一个带有乐谱及其伴奏的 .maestropro 文件,供另一位 Maestro Pro 用户使用。
1276|“导出视频”把乐谱变成音乐随之流动的影片,带声音。
1277|Maestro Pro 也会出现在其他 App 的分享面板中,用于它能打开的文件,并导入它们。
1278|最多八台运行 Maestro Pro 的设备可以彼此同步演奏(高级模式)。
1279|连接
1280|打开各自的声部,然后一人选择“一起演奏”,再选“开始会话”。其他人选择“加入会话”并选取该设备。主持人需要允许每位演奏者加入。如被询问,请允许“本地网络”权限。
1281|任一设备上的播放、暂停、定位和速度更改都会同步到所有设备,因此老师和学生或整个合奏团都保持同步。每位演奏者保留自己的声部、调和乐器;设备逐小节对齐。
1282|一个会话最多可加入八台设备。如果使用无线扬声器或耳机,“微调”滑块可让你的声音提前或延后。
1283|版本历史与 GitHub
1284|保存乐谱的版本,在分支上尝试想法,合并回来,并把一切保存在 GitHub 上。
1285|版本与分支
1286|在乐谱编辑器中点按“历史记录”。“存储版本”保留一个可返回的快照。在编辑器中存储也会记录一个。“新建分支”开始一条单独的编辑线,从现在或任何更早的版本开始,让你可以尝试新东西而不触碰主乐谱。
1287|“回滚到此版本”会把较早的快照恢复为一个新版本,因此什么都不会丢失,你还可以撤销回滚。切换分支会先存储你未存储的编辑。
1288|“合并”逐小节把另一个分支并入当前分支。只在一个分支上更改的小节会过来;两个分支都更改的小节会冲突,由你选择保留你的还是采用对方的。小节按编号匹配,因此在一个分支早期添加或移除的小节可能让其余小节显示为冲突。
1289|分出
1290|“分出为新乐谱”把任何版本或某分支的最新版本变成资料库中一份独立的乐谱,带有全新的历史。
1291|在“历史记录”中选择“连接到 GitHub 仓库”并输入 所有者/仓库。“推送到 GitHub”把每个版本和分支作为真正的 Git 提交和分支发送,乐谱为一个 MusicXML 文件。“从 GitHub 拉取”带入在别处制作的版本。
1292|它需要对仓库内容具有读写权限的 GitHub 令牌。在“GitHub 音轨”的“访问令牌”下添加。它保存在你的钥匙串中。
1293|在 GitHub 上已分道扬镳的分支会以 名称-github 的形式到来,以便你合并它。PDF 乐谱没有历史记录;编辑 PDF 会存储一份单独的副本。
1294|按需生成的练习材料。
1295|制作音阶
1296|在主屏幕上选择“音阶与琶音”,选取类型(大调、小调、布鲁斯、琶音等)和一个调。会为它创建一份乐谱并添加到资料库,随时可演奏、移调和放慢。
1297|标注
1298|像在纸质乐谱上一样在页面上做标记。
1299|在页面上绘制
1300|在工具栏中开启“标注”,用 Apple Pencil 通过工具面板绘制:钢笔、记号笔、铅笔、颜色和橡皮擦。墨迹随乐谱保存,并在演奏时显示。
1301|每个缩放大小保留自己的绘制,使其与音乐保持对齐。
1302|“导出为 PDF”和“打印”会包含你当前所见的调和缩放下的墨迹。
1303|在 Mac 上,几乎所有操作都有键盘快捷键,显示在“播放”“乐谱”和“显示”菜单中。在带键盘的 iPad 上,按住 Command 键可查看它们。每个快捷键都可更改。
1304|更改快捷键
1305|打开“设置”▸“键盘快捷键”。点按一个快捷键,然后按下你想改用的按键。“删除”移除快捷键,Esc 保持原样。已被占用的快捷键会转移到你指定的操作上,页面会说明。快捷键旁的箭头将其还原,“全部还原为默认”还原所有。
1306|单个按键(如空格键)只在你没有在输入框中打字时才有效。
1307|开头的快捷键
1308|设置与辅助功能
1309|“设置”包含适用于各处的选项。
1310|外观
1311|“外观”可选浅色、深色或跟随系统。“高亮颜色”选择点亮演奏音符的颜色;工具栏使用你的强调色。高级模式有“自定每种颜色”。
1312|缩放、深色乐谱、跟随播放和三种高亮在这里有默认值,任何乐谱都可以覆盖。
1313|App 图标
1314|“设置”有一个“App 图标”网格:原版、纸张、午夜、黄铜、日落和森林风格,英国国旗、骄傲和跨性别骄傲,以及每种乐器一个(钢琴、管风琴、原声吉他、贝斯、长笛、单簧管、中音和次中音萨克斯、小号)。点按一个,iPadOS 会切换图标并告诉你。
1315|每个图标都有浅色、深色和着色版本,跟随你的主屏幕样式。Mac 只保留一个 Dock 图标,所以该网格只在 iPad 上。
1316|纸张、桌面、按钮和控制面板被绘制成真实的材质。在“表面”下,你可单独调高或调低“纸张纹理”“页面阴影与折角”“桌面皮革”“皮革按钮”和“拉丝金属”(最多两倍),或关闭“拟真表面”以获得更平的外观。“高对比度”也会关闭它们。
1317|演奏
1318|演奏时保持屏幕常亮、演奏时隐藏资料库、默认开启节拍器和预备拍、打开乐谱时开始演奏、默认练习速度以及默认乐器。
1319|App 文字大小、粗体文字、高对比度、较大的播放控件和减弱动态效果。
1320|“节拍闪光”和“节拍震动”(触感)让脉搏可见可感。“用旁白播报小节”在小节经过时朗读小节号。
1321|控件带有旁白标签和提示。
1322|疑难解答
1323|如果出现问题,请先在这里查看。
1324|常见问题
1325|PDF 播放的拍数不对:在检查器中设置“每小节四分音符数”,或在它首次打开时回答拍号问题。
1326|“等我”或调音器说听不到我:在设备“设置”▸“隐私”▸“麦克风”中允许麦克风,然后在“设置”▸“聆听”中调高“麦克风灵敏度”。一次只弹一个音,并压低其他声音。如果它仍听成错误的八度,请尝试“接受任意八度”。
1327|PDF 中的音符看起来读错了:只能读取印刷的记谱,扫描件需要端正清晰。对于 App 读不好的扫描件,请改为导入 MusicXML 文件;网上有许多免费的。
1328|伴奏开始得晚或早:拖动音轨标记,或使用“延迟开始”。用“匹配调与速度到音轨”重新聆听。
1329|Band-in-a-Box 文件无法读取(封闭格式)。在 Band-in-a-Box 中,把记谱存为 MusicXML,把伴奏存为音频。
1330|“导入乐谱”没有反应或文件显示为灰色:在“文件”浏览器中选择“所有文件”,或把文件拖到窗口上。
1331|爵士曲目在第一次添加时需要联网。
1332|编辑器中小节过满:关闭“自由编辑”,或删除一个音符,编辑器会整理小节。
